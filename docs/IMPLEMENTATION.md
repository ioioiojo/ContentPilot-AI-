# 小团队试用版实施范围

目标：在本地验证内容运营闭环后，提供可上传至已有网站服务器的独立部署包。当前不连接服务器；本机已接用户指定 flux-code.cc / gpt-5.5 文字接口，升级验证使用模拟服务，不额外调用付费模型。

- 账号：管理员通过命令行初始化账号，登录、退出、修改密码、创建及停用成员；服务端用户隔离、会话过期、CSRF 与登录限速。
- 资料：用户保存商品事实与来源，任务创建时保存不可变快照；不将固定话题冒充实时热点，不自动抓取任意 URL。
- 执行：提交立即返回任务编号；独立 worker 处理数据库队列，租约防重复认领、硬超时、有限重试、重启后恢复；保存步骤耗时、版本、审核和错误。
- 审核：始终经过人工审核，支持编辑、驳回、通过及导出；乐观锁防覆盖，规则失败不允许通过。
- 网页：中文操作界面，任务状态、内容版本、资料与审核记录、个人统计、管理用户。
- 部署：单机 Docker Compose（web、worker、PostgreSQL），仅绑定 127.0.0.1:18080，接入既有反向代理，提供备份恢复说明。

队列选择：通过数据库原子条件更新领取任务，避免业务数据和消息队列双写不一致。单个 worker 顺序执行，扩展 worker 可并发认领。服务器使用 PostgreSQL，本地 SQLite 用于单 worker 演示。当前不需要 Redis/RQ。

0.4.0 增加版本化业务技能、真实 stdio MCP 调用、人工质量标注与离线评测、审核后素材队列、授权发布网关适配、手动发布登记、累计效果快照和同商品反馈。数据库v2仅增加表，不更改用户原有记录。MCP失败会明确报错，不将本地示例冒充实时热点。

0.5.0 增加 production/staging 配置门槛、每账号并发与滚动 24 小时额度、提交暂停开关、数据库 worker 心跳与 /ready、管理员聚合诊断，以及停写后升级备份、恢复前备份、停机回滚和运维脚本。schema v3 仅新增 worker_heartbeats 表。新任务默认总执行预算为 1，旧任务快照预算保持。任务数量限制不代表供应商货币消费封顶。

0.6.0 增加按账号隔离的参考帖库、关键词打开小红书搜索、可配置搜索网关和限速、参考内容快照及二创要求。生成、审核与修改均传入参考数据和原创表达规则，长段原文或完整长标题重复阻止人工批准。schema v4 新增参考帖/搜索记录表。参考正文不是商品事实或指令，重复检测不等于原创或版权认证。

0.6.1 增加 TikHub 小红书 App V2 搜索→正文读取→整批导入适配，支持排序和笔记类型、数量上限 5、固定错误提示、不自动重试及密钥隐藏配置命令；保留旧网关协议和 schema v4。现无 TikHub 密钥，HTTP/浏览器验证均为模拟服务，实际嵌套数据结构与真实搜索仍待首次接口验收；不得宣称小红书官方授权或已接通。

0.7.0 使用 schema v5，新增加密服务配置/审计、账号隔离知识文档与相关性检索、真实热点批次、审稿资格/任务分配、持久化工作流断点、指标订阅和采集任务。web/worker 使用同一配置密钥；每个请求/执行持有配置快照，避免供应商地址与密钥错配。所选完成素材与当前内容/版本匹配后可附加到发布网关。采集缺失指标保留 null，仅完整业务指标进入转化率计算；TikHub 公共互动不能推算后台成交。

交付边界：Mock 数值仅用于流程演示；真实模型质量、线上业务指标、服务器容器实测要在相应环境中验证。图片/视频/发布/热点/完整指标仍需供应商、权限、实际协议及真实测试。知识检索是关键词检索，不是向量语义库；观察性对比不是随机 A/B 实验。断点仅跳过已持久化的完成步骤，不能保证供应商调用恰好一次。系统不宣称完整合规审核或独立事实核查能力。
